# HomeGadgets.ca Tools

Public, credential-free client tools for querying Canadian price data from
[HomeGadgets.ca](https://www.homegadgets.ca) — Canada's independent,
ad-free price-comparison engine for appliances and home electronics.

## What's here

| Tool | Status | Description |
|------|--------|-------------|
| **MCP Server** | Coming soon | Connect an AI assistant to HomeGadgets prices (catalog + live). |
| **Browser Extension** | Planned | One-click live price checks while you shop. |
| **Desktop App** | Planned | Self-contained live price comparison — no AI needed. |

## Security & privacy

These tools are **credential-free**. They ship with no API keys, no database
logins, and no secrets. They query only HomeGadgets' public catalog API, and
live price checks run on your own machine using your own connection. No account
required. Read-only — these tools report prices; they never place orders.

Use at your own risk. Prices are the lowest in-stock value observed and are
not a guaranteed lowest — always confirm at the retailer before buying.
