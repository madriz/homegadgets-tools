# Contributing

[Français](#contribuer)

Issues are welcome. If something in these tools or this documentation is
wrong, unclear or broken, open an issue with:

* which tool (MCP server, public API, extension, Price Now) and which version;
* what you did, what you expected, and what happened;
* for a price question, the product's model number and the retailer.

A wrong price or a missing product is also welcome as an issue, or through
<https://www.homegadgets.ca/contact>.

**Pull requests:** this repository holds documentation only. There is no source
code here and no data. We do not accept pull requests that add or change price
data, product data or retailer data. Corrections to the documentation are
welcome as an issue first.

**Security problems:** do not open a public issue. See [SECURITY.md](SECURITY.md).

Do not put personal information in an issue.

## Contribuer

Les signalements de problèmes (issues) sont les bienvenus : indiquez l'outil,
sa version, ce que vous avez fait et ce qui s'est passé. Ce dépôt ne contient
que de la documentation, ni code source ni données. Nous n'acceptons aucune
demande de fusion (pull request) qui ajoute ou modifie des données de prix, de
produits ou de détaillants. Pour un problème de sécurité, voir
[SECURITY.md](SECURITY.md).
